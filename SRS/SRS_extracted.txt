1. نظرة عامة على المشروع

1.0 وصف المشروع
MyLoundreyPlus هي منصة SaaS متكاملة لإدارة المغاسل في السوق الخليجي واليمن. تربط المنصة بين العملاء الباحثين عن خدمات غسيل وكي احترافية، وأصحاب المغاسل الراغبين في رقمنة أعمالهم وتنمية قاعدة عملائهم، عبر ثلاثة تطبيقات متكاملة تديرها لوحة تحكم مركزية.

4.1تسجيل الدخول

4.2إدارة الحساب والملف التجاري
تعديل كلمة المرور (القديمة + الجديدة + التأكيد)

إدارة أوقات العمل اليومية والإجازات
التواصل مع الدعم الفني (اتصال أو مراسلة)
4.3نظام الفواتير (POS)

مكونات الفاتورة
معلومات العميل: الاسم + رقم الهاتف + الموقع (إن وُجد)
رقم الفاتورة (يُولَّد تلقائياً) + تاريخ الإنشاء
جدول الأصناف: القسم — الصنف — الكمية — نوع المعالجة (مستعجل / عادي مع تاريخ التسليم المتوقع)
نوع الخدمة لكل صنف: كوي فقط / غسيل فقط / غسيل + كوي
السعر لكل صنف
طريقة اختيار الأصناف: وضع علامة صح ومقابلها حقل الكمية
الرسوم الإضافية: رسوم الاستعجال (إن وُجد) + الضريبة (إن وُجد)
المجموع الفرعي + الخصم + الضريبة + الإجمالي النهائي

إنشاء الفاتورة
إنشاء فاتورة لعميل مسجل: بمسح QR أو إدخال Unique ID
إنشاء فاتورة لعميل غير مسجل (زبون عادي): بإدخال الاسم + رقم الهاتف + الموقع (اختياري)
إضافة الأصناف مع تحديد نوع الخدمة والكمية والاستعجال
تحديد نوع الدفع: نقدي / شبكة / آجل / إلكتروني

فلترة وعرض الفواتير
عرض الفواتير حسب الحالة: الكل — جاهزة — غير جاهزة — قيد التجهيز — تم التسليم
فلترة زمنية: اليوم / الشهر / السنة / الساعة / فترة من تاريخ إلى تاريخ
بحث برقم الفاتورة مباشرة
بطاقة الفاتورة تعرض: رقم الفاتورة — تاريخ الإنشاء — تاريخ التسليم المتوقع — الحالة الحالية

4.4طباعة ومشاركة الفاتورة
طباعة حرارية عبر الطابعة البلوتوث
تصدير PDF ثم مشاركة عبر البلوتوث
إرسال عبر واتساب على رقم العميل مباشرة
إرسال إشعار داخل تطبيق العميل (إذا كان لديه حساب)
الجمع بين عدة خيارات في وقت واحد: واتساب + تطبيق العميل
عند الضغط على الفاتورة تظهر جميع تفاصيلها

4.5إدارة قائمة الأصناف والأسعار
إنشاء أقسام (رجالي / نسائي / أطفال / إلخ)
إضافة صنف جديد مع تحديد السعر
تحديد سعر الكوي وسعر الغسيل بشكل منفصل لكل صنف
تفعيل الضريبة وتحديد قيمتها (قابل للتعديل في أي وقت)
تفعيل رسوم الاستعجال وتحديد قيمتها (قابل للتعديل)
تفعيل / تعطيل أصناف مؤقتاً بدون حذفها

4.6إدارة العملاء (CRM)
فلترة العملاء بالتاريخ (يوم / شهر / سنة / ساعة / فترة زمنية) أو البحث بالاسم أو الـ ID
عرض جميع العملاء الذين تعاملو معا المغسلة 
بطاقة عرض العملاء الاسم عدد الفواتير من هذا المغسلة 
عند الضغط على العميل يقوم بعرض الاجل (الدين الذي عليه) عدد الفواتير اجمالي المبالغ المدفوعة و سجل كل فواتير العميل من هذا المغسلة 
عرض الفواتير على شكل بطاقة عرض عند الضغط عليه يعرض تفاصيل الفاتورة
تتبع المبالغ الآجلة المتأخرة
إرسال إشعار تذكير: عبر واتساب أو داخل التطبيق أو كليهما
التواصل مع العميل: الاتصال برقمه أو المراسلة داخل التطبيق أو واتساب
4.7الحجز وإدارة المواعيد
عرض قائمة الحجوزات القادمة
تأكيد أو رفض طلبات الحجز
تحديد الأوقات المتاحة للحجز

5. متطلبات لوحة الإدارة (Dashboard)

5.1 إدارة المغاسل
عرض جميع المغاسل المسجلة مع فلترة بالحالة (فعّال / معلق / محظور / تجريبي)
معالجة طلبات تسجيل المغاسل الجديدة (قبول / رفض)
تفعيل / تعليق / حظر أي مغسلة
عند الضغط على حساب مغسلة: عرض صفحة تفاصيل كاملة تشمل الملف الشخصي + الاشتراك + الإيرادات + التقييم
إمكانية تعديل بيانات المغسلة مباشرة من اللوحة
عرض جميع الأجهزة المرتبطة بحساب المغسلة مع تفعيل أو إلغاء تفعيل أي جهاز

5.2 إدارة العملاء
عرض جميع العملاء المسجلين
عند الضغط على حساب عميل: عرض تفاصيل الملف الشخصي كاملة معا التقيمات 
إمكانية تعديل بيانات العميل مباشرة من اللوحة
عرض جميع الأجهزة المستخدمة في الحساب مع إمكانية إلغاء تفعيل أو تفعيل أي جهاز
تفعيل / تعليق / حظر حساب أي عميل

5.3 إدارة الاشتراكات
إنشاء وتعديل خطط الاشتراك (شهري / سنوي / تجريبي)
تحديد سعر كل خطة وميزاتها
إنشاء عروض اشتراك موسمية للمناسبات (العيد الوطني، رمضان، إلخ) مع تحديد مدة صلاحية العرض
إنشاء وإدارة أكواد الخصم (Promo Codes)
تجديد اشتراك مغسلة يدوياً
قائمة بالمغاسل التي على وشك انتهاء اشتراكها

5.4 إدارة الإعلانات
إضافة إعلان: عنوان + صورة/فيديو + نص + رابط
تحديد الجمهور: العملاء / المغاسل / الجميع
جدولة الإعلانات (تاريخ البداية والنهاية)
تعديل وحذف الإعلانات
إحصاءات مشاهدة الإعلانات

5.5 الدعم الفني والشكاوى
استقبال ومتابعة تذاكر الدعم من المغاسل والعملاء
الرد على التذاكر مباشرة من اللوحة
تصنيف التذاكر: مفتوح / قيد المعالجة / مغلق
استقبال مكالمات ورسائل مباشرة من داخل التطبيق
تعديل أرقام التواصل الظاهرة للمستخدمين

5.6 التقارير والإحصاءات
إجمالي إيرادات الاشتراكات الشهرية والسنوية
عدد المغاسل النشطة / التجريبية / المعلقة
نمو المستخدمين (يومي / أسبوعي / شهري)
المغاسل الأكثر نشاطاً
إحصاءات الإعلانات والعروض

5.7 إعدادات النظام
تعديل أرقام التواصل وروابط التواصل الاجتماعي
تحديد مدة الفترة التجريبية

6.6 إدارة الأجهزة وجمع بياناتها
آلية جمع بيانات الجهاز
عند كل تسجيل دخول ناجح، يقوم التطبيق تلقائياً بجمع وتخزين المعلومات التالية بدون أي تدخل من المستخدم:
معرف الجهاز الفريد (Device ID): رقم ثابت لا يتغير حتى لو أُعيد تثبيت التطبيق
نوع الجهاز: هاتف أو تابلت — يُقرأ تلقائياً من النظام
نظام التشغيل: iOS أو Android مع رقم الإصدار — يُقرأ تلقائياً
موديل الجهاز: مثل iPhone 15 Pro أو Samsung Galaxy S24 — يُقرأ تلقائياً
اسم مخصص: يستطيع المستخدم اختيارياً تسمية جهازه مثل "آيفون الشغل" لتمييزه في القائمة
رمز الإشعارات (FCM Token): يُحدَّث تلقائياً عند كل تسجيل دخول
تاريخ ووقت آخر تسجيل دخول: يُسجَّل تلقائياً
قواعد إدارة الأجهزة
الحد الأقصى لعدد الأجهزة لكل حساب يُحدَّد من إعدادات النظام في لوحة الإدارة
الجهاز الأول يصبح الجهاز الأساسي تلقائياً
عند تجاوز الحد الأقصى يظهر تنبيه للمستخدم لإدارة أجهزته
المستخدم يستطيع إلغاء تفعيل أي جهاز عن بُعد لحماية حسابه من الاختراق
عند تسجيل الدخول من جهاز جديد غير معروف، يُرسَل إشعار تنبيه للمستخدم

10. قائمة التحقق قبل البدء
10.1 قرارات تم اتخاذها 
إطار عمل Backend: NestJS (Node.js + TypeScript) — مؤكد وتم البدء به
بوابة الدفع: مؤجلة — الهيكل سيدعم الدفع مسبقاً، يُفعَّل عند توفر العقد والميزانية
قاعدة البيانات: PostgreSQL 16 — مؤكدة وجاهزة
الكاش: Redis — مؤكد ويعمل
الإشعارات والمحادثة: Firebase FCM + Firestore — مؤكد
الخرائط: Google Maps API — مؤكد
تطبيقات المحمول: React Native + Expo — مؤكد (iOS + Android)
لوحة الإدارة: React.js + Vite — مؤكد
التقارير: Python FastAPI كـ Microservice منفصل — مؤكد
OTP: عبر الإيميل (مجاني) في مرحلة التطوير — SMS يُضاف لاحقاً
10.2 قرارات معلقة — تُحدد قبل الإطلاق
تحديد خطط الاشتراك وأسعارها النهائية
تحديد الفترة التجريبية المجانية (أسبوع / أسبوعان / شهر)
تحديد قيمة رسوم الاستعجال والضريبة الافتراضية
اختيار مزود الاستضافة (DigitalOcean / غيره)
تحديد بوابة الدفع الخاصة باليمن
10.3 ما يجب توفيره قبل البدء
حساب Google Cloud — للخرائط وFirebase — متوفر ✅
مزود OTP عبر الإيميل (مجاني — Nodemailer أو Resend) — يُستخدم في مرحلة التطوير والإطلاق الأول
مزود SMS للـ OTP (Unifonic أو Msegat) — يُضاف لاحقاً عند توفر الميزانية
بوابة الدفع الإلكتروني — الهيكل جاهز، يُفعَّل عند الإطلاق
سجل تجاري لنشر التطبيق على App Store + Google Play — مطلوب قبل الإطلاق فقط
